# LifeOS 路线图

## 已完成：本地可运行原型

- 三维宇宙和领域切换
- Markdown 本地资料
- 快速记录
- Ollama 流式对话
- 资料标题引用
- 模型状态检查
- 响应式界面

## 下一步：真正可用的个人版本

- 全量 Markdown 增量索引
- `bge-m3` 向量检索
- 日期、领域、标签过滤
- 一个简单的文档阅读页
- 搜索结果与原文定位
- 20～30 条问题的评测集

## 再下一步：成长 Skill

- 每日复盘
- 周度成长报告
- 健康趋势分析
- 学习与面试教练
- RAG 项目排障
- 知识连接推荐
- 长期记忆审阅与确认

## 后期：混合云与多设备

- 本地/云端模型切换
- 局域网访问
- 加密同步
- 备份与恢复
- 按领域的数据授权
- 账号、设备与权限管理
